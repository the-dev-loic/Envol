🔑 Connexion à GitHub

Cette page modifie ton dépôt à ta place. Il lui faut un jeton GitHub (une sorte de mot de passe limité à ce dépôt). Il reste enregistré uniquement dans ce navigateur, sur ton PC.

Comment créer le jeton (une seule fois, 2 minutes)
  1. Ouvre github.com › Settings › Fine-grained tokens › Generate new token.
  2. Token name : Envol admin · Expiration : au choix (ex. 1 an).
  3. Repository access : Only select repositories → choisis Envol.
  4. Permissions › Repository permissions : Contents = Read and write, et Pages = Read-only.
  5. Clique Generate token, copie le jeton (github_pat_…) et colle-le ci-dessous.

⚠️ N'utilise pas cette page sur un ordinateur partagé.

⚙️ Réglages du jeu

Modifie, puis « Enregistrer sur GitHub ». Le jeu en ligne est mis à jour en 1 à 2 minutes (fichier reglages.json).
